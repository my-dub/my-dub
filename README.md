# my-dub

## Сервисы

### my-dub-core: [github](https://github.com/my-dub/my-dub-core)
Сервис, который управляет пользовательскими проектами дубляжа: создаёт их, отслеживает статусы и запускает нужные этапы обработки. Именно этот сервис связывает между собой приложение, ML-обработку и хранилище файлов.

### my-dub-ml: [github](https://github.com/my-dub/my-dub-ml)
Сервис, в котором происходят все этапы дубляжа: скачивание видео, распознавание речи, перевод, синтез голоса и сборка итогового результата. Работает как с обычными файлами, так и с онлайн-видео и стримами.

### my-dub-auth: [github](https://github.com/my-dub/my-dub-auth)
Сервис авторизации, который отвечает за регистрацию, вход и проверку пользователя.

### my-dub-content: [github](https://github.com/my-dub/my-dub-content)
Сервис для хранения и выдачи медиафайлов. Через него платформа загружает исходные видео, сохраняет результаты дубляжа и отдает контент для скачивания или потокового воспроизведения.

### my-dub-app: [github](https://github.com/my-dub/my-dub-app)
Мобильное Android-приложение MyDub, через которое пользователь работает с сервисом. Предоставляет возможности "живого" дубляжа с микрофона, стримов и видео, а так же офлайн дубляж в виде пользовательских проектов.

### Само приложение можно скачать из этого репозитория, файл [my-dub.apk](https://github.com/my-dub/my-dub/raw/refs/heads/main/my-dub.apk)
